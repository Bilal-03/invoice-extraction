# 🚀 Quick Start Guide - Upload to GitHub in 5 Minutes

## ⚡ Fast Track (For Beginners)

### Step 1: Create GitHub Account
1. Go to https://github.com/join
2. Sign up with your email
3. Verify email

### Step 2: Create New Repository
1. Click "+" icon (top right) → "New repository"
2. Name: `invoice-extraction`
3. Description: "AI-powered invoice data extraction"
4. ✅ Make it **Public**
5. ❌ Don't initialize with README
6. Click "Create repository"

### Step 3: Upload Files (Easiest Method)

**Option A: Web Upload (No Git needed!)**
1. On your new repository page
2. Click "uploading an existing file"
3. Drag ALL these files into the browser:
   - ✅ app.py
   - ✅ requirements.txt
   - ✅ README.md
   - ✅ Dockerfile
   - ✅ .gitignore
   - ✅ LICENSE
   - ✅ templates/ folder (upload separately)
4. Scroll down, click "Commit changes"

**Option B: GitHub Desktop (Download first: https://desktop.github.com)**
1. Open GitHub Desktop
2. File → Add Local Repository
3. Choose your project folder
4. Publish repository
5. Done!

### Step 4: Make It Look Professional
1. Go to your repository
2. Click ⚙️ next to "About"
3. Add topics: `python` `machine-learning` `computer-vision` `ocr` `flask`
4. Save

### Step 5: Update README with Your Info
1. Click on README.md
2. Click pencil icon ✏️
3. Replace:
   - `YOUR_USERNAME` → your GitHub username
   - `your-email@example.com` → your email
4. Commit changes

## 🆘 Having Issues?

**Can't find files?**
- They're in the `invoice-extraction` folder you downloaded

**Upload failed?**
- Try uploading one file at a time
- Make sure files aren't too large (>100MB)

**Need Git installed?**
- Windows: https://git-scm.com/download/win
- Mac: Open Terminal, type `git --version` (auto-installs)
